# 시스템 프롬프트 및 전처리 방식 문서

## 1. 시스템 프롬프트

### ChatGPT
```
당신은 자연어를 NEO Knowledge Base 형식으로 변환하는 전문가입니다. 
사용자의 자연어 입력을 정확한 지식 베이스 형식으로 변환해주세요.
- 주어와 서술어를 명확히 구분하여 변환
- 관계와 속성을 정확하게 매핑
- 불필요한 정보는 제외
```

## 2. 전처리 방식

### 파싱 방식
1. **주어/서술어 지정**
   - 문장의 주어와 서술어를 명확히 구분
   - 복합 주어나 복합 서술어는 개별적으로 처리

2. **관계 추출**
   - 주어와 서술어 간의 관계를 명확히 식별
   - 속성과 관계를 구분하여 처리

3. **속성 매핑**
   - 각 주어에 대한 속성을 정확하게 매핑
   - 속성값의 타입을 적절히 지정

### 전처리 단계
1. 문장 분리
2. 주어/서술어 식별
3. 관계 추출
4. 속성 매핑
5. NEO Knowledge Base 형식으로 변환

## 3. 후처리 방식

### 검증 단계
1. 변환된 형식의 유효성 검사
2. 필수 필드 존재 여부 확인
3. 데이터 타입 검증

### 정규화
1. 불필요한 공백 제거
2. 특수문자 처리
3. 일관된 형식 적용
