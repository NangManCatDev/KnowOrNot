# NEO 벤치마크 시스템 파이프라인 요약

## 🎯 시스템 개요

NEO 벤치마크 시스템은 **자연어 질의를 NEO 언어로 변환하여 지식베이스에서 논리적 추론을 수행하는 복합적인 AI 파이프라인**입니다.

## 🔄 핵심 파이프라인 흐름

### 1. QA 챗봇 파이프라인 (가장 복잡한 파이프라인)
```
사용자 질의 → Agent 대화 → 정보 구조화 → RAG 검색 → NEO Query 변환 → NEO Engine 실행 → 응답 생성
```

**특징:**
- **Agent 대화 모드**: 사용자와의 대화를 통해 정보를 구조화
- **RAG 검색**: Chroma 벡터 데이터베이스를 통한 관련 지식 검색
- **NEO Query 변환**: 자연어를 구조화된 NEO 질의어로 변환
- **NEO Engine 실행**: 논리적 추론을 통한 정확한 답변 생성

### 2. 벤치마크 파이프라인
```
모델 선택 → 질의 로드 → 복합질의 단순화 → 모델별 실행 → 결과 수집 → 성능 분석 → 시각화
```

**특징:**
- **복합질의 단순화**: 복잡한 문장을 단순한 문장들로 분리
- **다중 모델 지원**: GPT, Gemini, 로컬 모델 동시 테스트
- **평가 기반 재생성**: 출력 품질을 평가하여 필요시 재생성

### 3. 지식베이스 생성 파이프라인
```
문서 입력 → 텍스트 추출 → LLM 변환 → 형식 변환 → 파일 저장
```

**특징:**
- **다양한 입력 형식**: 텍스트, 파일(PDF, DOCX), URL 지원
- **다양한 출력 형식**: NEO 형식(.kb), 자연어 형식(.nkb), JSON 형식(.json)

## 🏗️ 시스템 아키텍처

### 모듈화된 설계
- **NEO Engine**: `engine.py` - 논리적 추론 엔진
- **Chroma RAG**: `chroma_rag.py` - 벡터 검색 시스템
- **전처리기**: `ollama_preprocessor.py` - 복합질의 단순화
- **모델 관리**: `LlamaServerManager` - 로컬 모델 서버 관리

### 확장 가능한 구조
- **플러그인 방식**: 새 모델, 템플릿, 평가 방식 쉽게 추가
- **독립적 모듈**: 각 모듈이 독립적으로 동작하여 유지보수 용이
